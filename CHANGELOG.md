# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-08-20

### Added

- Quaternion-based spacecraft attitude kinematics.
- Nonlinear rigid-body rotational dynamics.
- Energy-based hybrid attitude controller.
- Backstepping hybrid attitude controller.
- Hysteresis-based switching logic for unwinding avoidance.
- Bounded quaternion measurement noise for robustness analysis.
- Chattering visualization using a filtered hybrid logic variable.
- Angular velocity and cumulative control-effort metrics.
- Comparison plots for different hybrid controller configurations.
- 3D spacecraft attitude visualization using PyVista.
- NASA Galileo spacecraft STL model for attitude visualization.
- Synchronized visualization of spacecraft motion and control signals.
- GIF recording of attitude-control simulations.
- Animated simulation demonstration in the project README.
